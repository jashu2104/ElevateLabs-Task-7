# Task 7 - Identify and Remove Suspicious Browser Extensions

## 🎯 Objective
Learn to spot and remove potentially harmful browser extensions to improve browser security.

## 🔹 Steps Followed
1. Opened browser’s extension/add-ons manager.
2. Reviewed all installed extensions carefully.
3. Checked permissions, developer details, and reviews for each extension.
4. Identified unused or suspicious extensions.
5. Removed unnecessary or suspicious extensions.
6. Restarted browser and confirmed smooth performance.

## 🕵️ Findings
- Example Suspicious Extension: **"XYZ Free Coupons"** (requested access to all websites, poor reviews).
- Example Suspicious Extension: **"ABC PDF Converter"** (unnecessary, low trust rating).
- These were removed to ensure safety.

## 📌 Key Learnings
- Extensions may pose security risks if they request excessive permissions.
- Always install from trusted developers and official sources.
- Remove unused extensions regularly to reduce risks.
- Malicious extensions can steal cookies, monitor browsing, and capture sensitive data.

## ✅ Outcome
- Improved browser performance and security.
- Gained awareness about risks associated with browser extensions.
